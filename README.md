# Quick Notes

Quick Notes is a native Mac app that lives in the menu bar. Click its icon or use your keyboard shortcut to open a floating note. Your changes save automatically on your Mac.

## Features

- Add headings, lists, highlights, and images to a note.
- Pin the compact window when you want it to stay open. It follows your Mac's light or dark appearance.
- Search your notes and reopen recent ones.
- Choose a keyboard shortcut and set appearance and launch-at-login preferences.

## Requirements

- macOS 14 or later to run the app.
- Xcode with Swift 5.10 or later to build it from source.

This repository holds the app's source code and tests. Your personal notes stay on your Mac and are not included.
