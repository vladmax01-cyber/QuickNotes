# Quick Notes 2.1.18 — Writing and sharing

This update brings together the changes made since the v2.1.11 download.

## Writing and formatting

- Paste formatted text with a consistent Quick Notes font while keeping useful bold, italic, color, image, and table content. Paste options let you keep the source formatting, match the note, or paste plain text.
- Paste tables from rich content, Markdown, or tab-separated text. Aa can also insert a table, convert selected text to a table, add a row, or turn a table back into text.
- Resize images to fit narrow notes and make it easier to continue writing after an image.
- Use text colors, highlights, headings, lists, checklists, quotes, alignment, and font-size controls from a more consistent Format panel. Pin that panel when you want it to remain open.
- Improved selection, highlight boundaries, list markers, and toolbar states. Formatting controls give light haptic feedback when enabled in Settings.

## Notes and windows

- Switch notes in the sidebar without closing it. Clicking in the editor closes the sidebar so you can write.
- Pin a note from its context menu or with Option-click in the sidebar; pinned notes stay at the top.
- Choose whether moving a note to Trash asks for confirmation. Deleted notes remain available in Settings until you empty Trash.
- Optionally reopen each note at its last reading position. Folding and reopening the window keeps the note's scroll position.
- Refined the layout of the floating Format panel, compact bar, resize controls, and toolbar as the note window changes size.

## Copy, share, and updates

- Copy a whole note with formatting and images, or copy only its text.
- Share or export a note as PDF; export rich text with images or plain text from the More menu or the note's context menu.
- Check for updates from Settings. Optional automatic checks show a small in-app notice when a newer GitHub release is available.

## Install

Download **QuickNotes-2.1.18.dmg** from the [GitHub release](https://github.com/vladmax01-cyber/QuickNotes/releases/tag/v2.1.18), open it, and drag **Quick Notes.app** to Applications. Requires an Apple Silicon Mac with macOS 14 or later. Notes remain stored locally on your Mac.

The app is signed locally but is not notarized by Apple. If macOS blocks the first launch, use **System Settings → Privacy & Security** to approve opening it.
